# 18. Performance Requirements

## Core Goals

- Fast first load
- Smooth interaction
- No mobile freezing
- No layout shifts
- Fast navigation
- Usable without WebGL

## Rules

- Lazy-load 3D scenes
- Dynamically import large components
- Use mobile-specific assets
- Compress all images
- Compress all GLB files
- Limit texture resolution
- Reuse geometry and materials
- Reduce draw calls
- Stop animation loops when scenes are off-screen
- Detect low-performance devices
- Reduce shadows and effects dynamically
- Provide static fallback visuals
